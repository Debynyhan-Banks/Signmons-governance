Introduce one repository-owned child wrapper only for IQ1's existing describe commands. It runs the same pinned SDK entrypoint with exactly the original command arguments in the existing deny-process-fork sandbox. Installed SDK files remain unchanged. The wrapper temporarily instruments ProcessHttpResponse in its own process; match exact IAM Get method/ServiceAccount response and expected request identity before inspecting. Other methods pass through without observation. Call the original method exactly once with the same response/request objects; preserve its return/exception and SDK stdout/exit behavior. Never alter retries, authentication, request parameters or decoded values.

Record fixed before/after labels from that same response: request/method/identity match; response HTTP status class SUCCESS/OTHER; input shape OBJECT/OTHER/INVALID/TOO_LARGE; disabled BOOL_TRUE/BOOL_FALSE/MISSING/NULL/OTHER; decoded disabled equivalent labels; decoder result RETURNED/RAISED. No headers, raw body, token, email/UID/project-number value, response digest or arbitrary error text. Inspect at most65536 response bytes; oversized/unparseable/foreign/multiple matching responses yield diagnostic unavailable, not a different provider outcome. Raw body references are transient; no HTTP/debug logging. This observes decoded HTTP content before SDK message conversion, not compressed network bytes.

Preserve existing stdout transport and IT1 timing. Use a separate small safe-only diagnostic receipt per existing describe invocation, maximum5 per operation (main baseline/readback, cleanup pre-disable/readback/final). No raw-output sidecar. Parent pre-binds exact exclusive path/operation/phase/ordinal and an opaque nonce; child publishes one immutable0600 fixed-schema JSON receipt inside the owned0700 operation root, using existing reserve/custody primitives. Parent validates binding, ownership, shape and <=4096 bytes before copying safe labels into corresponding existing final-result observation. Foreign/missing/partial/extra receipt is diagnostic UNKNOWN; never infer state from it or overwrite it. No receipt reuse across calls/operations. Extend only IQ1's explicit journal filename allowlist to these five fixed slots. Final evidence inventory remains bounded.

Diagnostic capture/publication/parsing failures must not replace the original SDK result or suppress independent cleanup. Diagnostic receipt creation must not compromise Journal.inspect for subsequent cleanup: all accepted slots require exact ownership/permissions and immutable safe schema; a corrupt/foreign file retains existing custody STOP, not a bypass. Tests must explicitly distinguish unavailable diagnostic from custody violation. If that distinction cannot be made within existing safe primitives, stop implementation and report the design blocker; do not weaken custody. Child wrapper exit/exception must preserve the native transport's no-retry behavior. Crash loss remains UNKNOWN; no durability guarantee beyond existing receipt primitives.
