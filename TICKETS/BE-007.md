# BE-007 - Tenant Lead-Source Reporting Pilot

## Ticket Summary

- Ticket ID: `BE-007`
- Repo: `signmons-calldesk-backend`
- Screen dependencies: `SCR-APP-018`, `SCR-APP-019`
- Objective: expose a privacy-safe, tenant-scoped lead-source report so the Eternity pilot can measure which website sources produce booked and completed jobs before the broader APP-014 dashboard is built.

## Owner Authorization

- Approved by the owner on August 30, 2026 as the next Signmons task after production lead-attribution acceptance.
- This is a narrow pilot exception to the marketing-first sequence. FE-013 returns to `Next` and resumes after this ticket is complete.

## In Scope

- Authenticated `GET /reports/lead-sources` endpoint.
- Tenant identity derived only from verified authentication context.
- Owner/admin/manager reporting-role enforcement.
- Required UTC `from` and `to` query bounds with a maximum 366-day range.
- Privacy-safe totals for created, booked, completed, cancelled, attributed and unattributed jobs.
- Lead-to-booking and booked-to-completed conversion rates.
- Source/campaign and landing-page breakdowns without customer names, phone numbers, addresses, messages or appointment-management credentials.
- Explicit metric lineage and automated tenant-isolation/calculation tests.

## Out of Scope

- Public reporting endpoints or a public dashboard.
- Cross-tenant benchmarks.
- Revenue estimates, invoices, payments or performance-fee billing.
- General Signmons APP-014 dashboard implementation.
- Modifying the public Eternity website before the backend contract is verified.

## Acceptance Criteria

- [ ] Endpoint rejects unauthenticated callers and unauthorized roles.
- [ ] Report uses the authenticated tenant and cannot accept a tenant override.
- [ ] Date validation is fail-closed and limits reports to 366 days.
- [ ] Booked includes jobs with accepted lineage; completed uses completed lineage; cancellations remain separately visible.
- [ ] Unattributed jobs remain visible instead of being silently discarded.
- [ ] Response contains no customer PII or conversational content.
- [ ] Focused calculation, authorization and tenant-isolation tests pass.
- [ ] Backend build, test and architecture gates pass.
- [ ] Contract, route matrix, evidence and handoff docs are updated.

## Evidence Plan

- Automated report service and access-guard tests.
- Production-safe report proof using only aggregate counts and the labeled Eternity attribution acceptance record.
- `evidence/BE-007/readiness-report.md` with command results and rollback notes.

## Risks

- Current job status alone can undercount previously accepted jobs; accepted/completed timestamps must remain part of metric lineage.
- Small pilot samples can produce misleading percentages; every response must include raw denominators.
- Reporting credentials must not be embedded in browser code.

## Commit Convention

- Backend commit: `feat(reports): add tenant lead-source summary`
- One focused backend commit.
