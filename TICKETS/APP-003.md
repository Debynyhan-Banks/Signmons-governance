# APP-003 - Job Completion Lifecycle Foundation

## Ticket Summary

- Ticket ID: `APP-003`
- Repo: `signmons-calldesk-backend`
- Screen dependency: `SCR-APP-005`
- Objective: let authorized tenant operators mark accepted work complete through an idempotent, tenant-isolated and auditable backend transition so operational and lead-source reporting can measure completed jobs accurately.

## Owner Authorization

- Approved by the owner on August 30, 2026 immediately after BE-007 reporting deployment.
- This is a narrow Eternity pilot operations exception. FE-013 returns to `Next` and resumes after APP-003 completion.

## In Scope

- Authenticated `POST /jobs/:jobId/complete` endpoint.
- Tenant identity from verified authentication context only.
- Owner/admin operator authorization for the pilot.
- Completion only from `ACCEPTED` or `IN_PROGRESS`.
- Idempotent replay for an already-completed job.
- Atomic job update plus `AuditLog` entry containing actor, prior status, trace identifier and completion timestamp.
- No customer PII in the response or audit metadata.

## Out of Scope

- Marking any real job complete without confirmed field status.
- Public Eternity website controls.
- Technician mobile workflow, bulk completion, invoices, payments or revenue recognition.
- Reopening completed or cancelled jobs.

## Acceptance Criteria

- [ ] Unauthenticated callers and non-owner/admin roles are rejected.
- [ ] Job lookup and update are constrained by authenticated tenant and job ID.
- [ ] Only `ACCEPTED` and `IN_PROGRESS` jobs can transition to `COMPLETED`.
- [ ] Repeated completion requests return the existing result without another state change or duplicate audit entry.
- [ ] First completion sets `completedAt` and records one tenant-scoped audit event atomically.
- [ ] Missing, cancelled, created and cross-tenant jobs fail without mutation.
- [ ] Response and audit metadata contain no customer PII.
- [ ] Backend build, focused tests, full tests and architecture check pass.
- [ ] Production deployment and unauthenticated-boundary smoke test pass without changing a real job.
