Diagnostic directory/receipt failure is not a source of provider authority and must not be consulted by the authoritative cleanup gate. Parent validates exact ownership/mode/link/inode/nonce/binding before accepting a receipt. Missing, partial, oversized, mismatching or duplicate receipt produces fixed diagnostic-unavailable status and no accepted labels; no automatic re-read/retry. A replaced/symlink/foreign directory or file is not followed, adopted, overwritten or recursively deleted. Record diagnostic-custody UNKNOWN and continue the already-authorized authoritative cleanup using the unchanged journal and resource ownership.
